# 来选课 · SHOU LXK

SHOU LXK 是潮涌核心社维护的上海海洋大学课程评价网站，可查询课程、教师与同学点评，分享课堂体验。

- **访问入口**：[lxk.shoumc.com](https://lxk.shoumc.com/)
- **项目仓库**：[Conduit-Club/SHOU-LXK](https://github.com/Conduit-Club/SHOU-LXK)

当前网站已提供独立的课程、教师与点评目录，并接入[社团统一账号](../shou-auth/)。旧版访问入口与认证跳转说明仅作历史记录，使用时请从上述现行入口进入。

## 使用说明

![SHOU LXK 首页，展示最新点评与站点概览](/img/screenshots/community/laixk.jpg)

*2026-10-15 在线页面实拍，课程与评价数量以当前网站为准。*

- [课程目录](https://lxk.shoumc.com/courses)：搜索课程名或课程号，按学院、类型、教师、学分等筛选，查看授课与点评。
- [老师目录](https://lxk.shoumc.com/teachers)：搜索姓名，查看授课信息与相关点评。
- [全站点评](https://lxk.shoumc.com/reviews)：搜索点评标题与正文，分页阅读同学体验。
- 登录并设置用户名后提交点评，可选择匿名或展示账号用户名与头像。
- 补充尚未收录的课程号与教师，普通用户的目录补充由管理员核实后公开。

同学评价属于个人体验，课程安排、选课要求与考核方式请以学校及任课教师发布的信息为准。

## 参与维护

代码、功能与站点问题请在 [SHOU-LXK Issues](https://github.com/Conduit-Club/SHOU-LXK/issues)反馈。课程和教师目录可通过站内补充入口提交；分享课堂体验时，请尊重不同感受，避免公开他人的私人信息。

本页于 2026-10-15 根据项目公开 README 与线上首页核对，功能开放范围以当前站点为准。
