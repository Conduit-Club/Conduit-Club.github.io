# 来选课

来选课提供上海海洋大学课程与教师评价查询，可按课程、教师等条件查找内容，参考其他同学分享的学习体验。

- **访问入口**：[lxk.shoumc.com](https://lxk.shoumc.com/)
- **原站入口**：[lxk.aaron212.com](https://lxk.aaron212.com/)
- **相关资料仓库**：[Conduit-Club/StructureAnalysis-shou-laixk](https://github.com/Conduit-Club/StructureAnalysis-shou-laixk)

当前社团访问入口为 `lxk.shoumc.com`；登录、注册会按页面提示跳转至原站。域名迁移说明见[2026.10.02 更新记录](../../updates/2026-10-02/)。

## 使用说明

![来选课首页，展示课程搜索与热门课程列表](/img/screenshots/community/laixk.jpg)

*2026-10-02 在线页面实拍，课程与评价数量以当前网站为准。*

课程、教师、搜索与分页可在社团域名下浏览。登录、注册会进入原站认证服务，认证后回到原站继续操作。

同学评价属于个人体验，课程安排、选课要求与考核方式请以学校及任课教师发布的信息为准。

## 维护与资料

在线服务由其他维护者维护，社团提供访问入口并维护相关分析、归档资料。上述组织仓库记录来选课的结构分析与数据归档工作；它与在线服务的维护职责有所区别。涉及账号或在线服务的问题，请通过原站提供的渠道联系维护者；资料仓库的问题可在对应 GitHub 仓库反馈。
