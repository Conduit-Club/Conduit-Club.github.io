# SHOUConnect 校园网络工具

[SHOUConnect](https://github.com/Conduit-Club/SHOUConnect) 是面向上海海洋大学校园网络访问的图形客户端，基于 EZ4Connect、ZJU-Connect 和 EasierConnect 改编，保留上游来源与第三方组件声明。

## 项目用途

- 通过图形界面配置校园网络连接与账号。
- 提供 EasyConnect 与 aTrust 相关连接能力。
- 提供代理设置与分流使用说明，具体支持范围以项目文档为准。

校园网络账号、访问权限与学校服务的开放规则仍以校方要求为准。

## 当前发行状态

截至 **2026-10-15**，组织仓库的 [Releases](https://github.com/Conduit-Club/SHOUConnect/releases) 尚无公开发行包。README 中部分下载链接与徽章仍指向 EZ4Connect 上游，不能据此视为 SHOUConnect 已发布的安装包。

需要使用或构建时，请先查看组织仓库的当前说明，并通过 [Issues](https://github.com/Conduit-Club/SHOUConnect/issues)确认适用平台与已知问题。
