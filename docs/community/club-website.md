# 社团官网与服务器档案

本站是潮涌核心社维护的 Minecraft 中文文档站，使用 Docusaurus，集中记录四服网络、玩家命令、社团项目与已确认的服务器更新。

## 公开入口

- [官网：www.shoumc.com](https://www.shoumc.com/)
- [文档镜像：wiki.shoumc.com](https://wiki.shoumc.com/)
- [GitHub Pages：conduit-club.github.io](https://conduit-club.github.io/)
- [源码：Conduit-Club.github.io](https://github.com/Conduit-Club/Conduit-Club.github.io)

站内链接保留当前访问域名，内容以 Markdown 为主，便于成员直接维护。

## 可以查阅什么

- [服务器总览](../../server/)与 Velocity、SMP、Create、SHOU 各服详情。
- [社团资源](../)：校园网站、客户端、插件与作品。
- [服务器更新日志](../../updates/)：已确认的公告与历史变更。
- [BlueMap 在线地图](https://map.shoumc.com/)：浏览已开放的世界地图。

## 参与维护

在[仓库 Issues](https://github.com/Conduit-Club/Conduit-Club.github.io/issues)反馈错误或提交 Pull Request。详细内容在 `docs/` 下维护；事实变更请提供来源，新增项目请附公开入口、用途与维护信息。

本站源码的许可见仓库 [LICENSE](https://github.com/Conduit-Club/Conduit-Club.github.io/blob/main/LICENSE)。图片、校园作品及链接项目遵循各自的来源与许可声明。
