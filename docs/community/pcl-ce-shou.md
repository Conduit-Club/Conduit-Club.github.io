# PCL-CE-SHOU 社团启动器

[PCL-CE-SHOU](https://github.com/Conduit-Club/PCL-CE-SHOU) 是潮涌核心社正在开发的 PCL-CE 社团版启动器，目前已有版本可以在 Releases 下载。

## 项目进展

启动器还在开发，目前主要在改进登录方式切换和更有潮涌核心社风格的界面，其他功能也会继续加入。

## 当前下载与登录

- **项目仓库**：[Conduit-Club/PCL-CE-SHOU](https://github.com/Conduit-Club/PCL-CE-SHOU)
- **下载版本**：[Releases](https://github.com/Conduit-Club/PCL-CE-SHOU/releases)

Java 登录 API 还需要申请。在申请完成前，Releases 中的版本只能使用 MUA Union 或 LittleSkin 登录；下载前请查看对应 Release 的说明。

服务器登录和认证地址说明见 [Velocity 登录与认证说明](../../servers/velocity/)。在 Minecraft 多人游戏中添加服务器时，推荐使用新的 `smp.shoumc.com`、`create.shoumc.com` 或 `shou.shoumc.com` 入口。

## 反馈与版本变化

构建、下载和已知问题请在 GitHub 仓库查看。遇到登录失败时，请先确认启动器版本和所选认证服务，再提交问题。
