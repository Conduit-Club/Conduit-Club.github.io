# 社团统一账号

[SHOU 潮涌核心社统一认证](https://auth.shoumc.com/)为社团校园服务提供共用的登录与账号资料入口。

## 从业务网站登录

在[来选课](../shou-laixk/)或[今日海大吃什么](../what-to-eat/)点击登录、注册，按页面提示前往统一认证，完成后返回原来的业务网站。也可直接访问 [auth.shoumc.com](https://auth.shoumc.com/)管理自己的账号资料。

来选课与餐饮站的公开说明均已接入统一账号。能否投稿、补充目录或管理内容，仍由各网站的规则和账号权限决定；登录后的公开署名方式请在提交前确认。

## 使用范围

这是校园网站的账号服务。Minecraft 启动器与服务器的登录方式，请查阅 [SHOU-Launcher](../pcl-ce-shou/)和 [Velocity 登录与认证说明](../../servers/velocity/)。

账号入口于 **2026-10-15** 核对，接入情况以各业务网站当前提示为准。
