# Discord 娱乐机器人

[Discord_Bot](https://github.com/Conduit-Club/Discord_Bot) 是基于 Discord Bot 与 FastAPI 的社区机器人项目，提供娱乐功能、AI 能力、可视化管理面板和 Minecraft 双向聊天桥。

## 主要功能

- AI 对话、对话摘要和绘图。
- 今日运势、抛硬币、是非题等娱乐命令。
- FastAPI 管理接口与网页控制台。
- Discord 与 Minecraft 的身份绑定、状态查询和聊天桥接。

## 项目信息

| 项目 | 内容 |
| --- | --- |
| 类型 | Discord Bot、FastAPI 服务与 Paper Bridge 插件 |
| 仓库状态 | 组织协作仓库（Fork） |
| 运行方式 | 支持 Pixi 与 Docker |

部署时需要自行配置 Discord、AI 渠道和其他第三方服务的访问凭据。不要把 `.env`、Token 或 API Key 提交到公开仓库。
