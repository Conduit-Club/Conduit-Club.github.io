# 2026.07.12 · SMP 与 DC Bot 互通

一、SMP 服务器 × DC Bot 互通更新
:new: 新增功能
1. 进服与退服提醒

玩家加入或离开 SMP 服务器时，DC 频道会自动发送通知：

:inbox_tray: Steve 加入了服务器
:no_mobile_phones: Steve 离开了服务器

方便群内成员及时了解服务器在线情况。

2. 在线玩家查询

在 DC 中使用：
/minecraft online
即可查看：

当前服务器在线人数
在线玩家列表
服务器在线状态

数据每 30 秒自动刷新，无需手动进入服务器查看。

3. 离线留言
可以通过 DC 给暂时不在线的 MC 玩家留言：

/minecraft tell 玩家名 留言内容

玩家下次进入服务器时，会在游戏内自动收到：

[DC留言] 留言内容

适合用于建筑协作、物品交接、活动通知等场景。

4. 聊天桥接优化
服务器启动后，不再一次性同步和输出 DC 频道中的历史消息。
更新后只会实时推送服务器启动之后产生的新消息，避免重启服务器时大量历史内容刷屏。
:wrench: 原有功能保持不变

以下功能仍可继续使用：

MC ↔ DC 聊天双向同步
/minecraft bind
/minecraft status

其中：
/minecraft bind：绑定 Discord 与 Minecraft 身份
/minecraft status：查看当前互通状态
二、创造建筑服更新
1. 默认创造模式
玩家进入创造建筑服后，将默认切换为创造模式（没有创造模式的自己切换一下模式）
同时开放游戏模式切换权限，方便进行建筑、测试与参观。

请勿使用相关命令干扰其他玩家。
2. 地皮数量扩容

每位玩家可拥有的地皮数量将由：

4 块 → 64 块

常用命令：

/plot auto
/plot claim
/plot home
/plot list mine
3. 地皮成员管理权限开放

更新后可使用以下命令管理地皮成员：

/plot add 玩家

添加协作者。只有地皮主人在线时，对方才能在地皮内建筑。

/plot trust 玩家

添加长期信任成员。即使地皮主人不在线，对方也可以建筑。

/plot remove 玩家

移除协作者、信任成员或黑名单成员。

/plot kick 玩家

将指定玩家踢出当前地皮。

/plot deny 玩家

禁止指定玩家进入当前地皮。

请合理使用 kick 和 deny，不要无故影响正常参观或协作。

4. 地皮合并与拆分

开放相邻地皮合并功能：

/plot merge all
/plot merge n
/plot merge e
/plot merge s
/plot merge w

需要拆分地皮时可使用：

/plot unlink

合并前请确认相邻地皮属于自己，或已满足对应的合并条件。

5. 开放更多地皮 Flag

创造服将开放更多地皮个性化设置，包括：

地皮内飞行
独立时间
独立天气
背景音乐
进入与离开提示
进入与离开通知
自动回血
自动恢复饱食度
无敌模式
瞬间破坏

查看当前可用 Flag：

/plot flag list

设置示例：

/plot flag set fly true
/plot flag set time 6000
/plot flag set weather rain
/plot flag set greeting 欢迎来到我的地皮
/plot flag set farewell 下次再来
/plot flag set invincible true

不同 Flag 的可选值可能不同，具体以游戏内提示为准。

6. 建筑操作日志

FAWE、WorldEdit 等批量建筑操作将接入 CoreProtect 日志记录。

出现以下情况时，可以联系管理员查询并视情况回滚：

大范围误操作
建筑被恶意破坏
批量替换错误
粘贴区域位置错误
其他可通过日志确认的建筑问题

请合理控制单次编辑范围，避免一次性处理过大区域造成服务器卡顿或产生大量日志。
