# 2026.11.19 · Terraria 社区服上线与社团服务更新

以下内容根据运营者本次确认的更新与公开仓库记录整理。尚未同步 Discord 频道已确认公告：[服务器更新频道](https://discord.com/channels/1481627208551501999/1504854748170293319)。

## Terraria 社区服开放

社团新开了一个 Terraria（泰拉瑞亚）社区服，想一起开荒、盖房或打 Boss 可以直接用原版客户端加入。

1. 打开 Steam 版 Terraria，推荐 PC 原版 `1.4.5.8`。在主菜单选「多人游戏 → 通过 IP 加入」，再选角色。
2. 地址填 `tr.shoumc.com`，端口填 `7777`。共用进服密码已经取消，无需填写。
3. 首次进服后，在游戏聊天栏输入 `/register 你的密码` 创建个人账户，再用 `/login 你的密码` 登录。账户密码至少 8 位，请单独设置。

这是一个中型经典难度世界，独立于 Minecraft 的 Velocity 代理网络。常用功能包括：

- 传送请求：`/tpa 玩家名` 发起传送，`/tpahere 玩家名` 邀请对方过来，接收方用 `/atp` 同意或 `/dtp` 拒绝。
- 返回死亡点：`/back` 传回上次死亡位置（冷却 20 秒）。
- 房屋圈地：`/house` 查看圈地和箱子保护指令（每人最多 2 间，单间面积上限 1000 格）。
- 留言墙：`/addnote 内容` 留言，`/notewall` 分页查看。
- 服务端同时装有 `Crossplay 2.5.0`（声明兼容 `1.4.5.0`–`1.4.5.8`，关闭旅行模式角色）、`DamageStatistic`（击杀 Boss 自动统计伤害）和 `History`（图格操作记录）。

动别人建筑和箱子前请先问过。完整插件清单与全部命令见 [Terraria 社区服说明](../../servers/tr/)。

## SHOU-Launcher 启动器更新

社团启动器 `SHOU-Launcher` 现已区分为稳定正式版与双端预发布版：

- **正式版 [v1.5.0 · wyc](https://github.com/Conduit-Club/SHOU-Launcher/releases/tag/v1.5.0)**（Windows x64）：调整首页四类账户来源布局与筛选，加入默认关闭的微软正版 3D 皮肤预览，同时接入 CurseForge 项目 API Key，支持 Mod 查询与官方优先、镜像回退下载。
- **预发布版 [v1.6.2 · xb](https://github.com/Conduit-Club/SHOU-Launcher/releases/tag/v1.6.2)**（Windows x64、Windows ARM64、Apple 芯片 Mac）：支持拖入整合包安装，支持检查模组、资源包和光影是否有更新；从旧启动器导入实例时会校验并复用已有游戏资源，只补下载缺失或损坏的文件。v1.6.2 会在 Java 启动后继续显示等待进度，直到游戏窗口真正出现；整合包加载慢时可以先返回启动器做别的事。

更新前先退出旧版。Windows 解压后把新的 EXE 放回原目录，Apple 芯片 Mac 用解压后的 `SHOU Launcher.app` 替换旧版即可。遇到实例迁移、账号或启动问题，可在启动器的「反馈」页提交。详见 [SHOU-Launcher 社团启动器说明](../../community/pcl-ce-shou/)。
