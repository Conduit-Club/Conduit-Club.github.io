# 2026.08.18 · SHOU 服务器更新公告

本轮更新主要调整了登录方式、性能配置，并加入了假人在线人数系统。

## 🔐 多渠道登录支持

服务器现在支持三种登录方式同时共存：

1. 微软正版登录
2. MUA Union 第三方登录
3. LittleSkin 第三方登录

当微软认证服务器异常、网络波动或无法正常登录时，推荐使用第三方认证方式。

### MUA Union 登录

用户中心：[MUA 用户中心](https://skin.mualliance.ltd/user)

认证服务器地址：

```text
https://skin.mualliance.ltd/api/union/yggdrasil
```

使用方法：

1. 打开 MUA 用户中心并登录。
2. 在用户中心找到“快速配置启动器”或认证服务器配置。
3. 将对应的配置按钮拖入 HMCL、PCL2 等启动器。
4. 在启动器中选择 MUA Union 登录。
5. 输入 MUA/Union 账号和密码，选择要使用的角色。
6. 启动 Minecraft 1.21.1，再使用平时的服务器地址进入。

如果启动器没有自动添加，也可以手动添加：

| 项目 | 内容 |
| --- | --- |
| 名称 | MUA Union |
| 地址 | `https://skin.mualliance.ltd/api/union/yggdrasil` |

:::warning

MUA Union 账号需要是 MUA 账号，或来自已经接入 Union 的成员皮肤站。

:::

### LittleSkin 登录

用户中心：[LittleSkin 用户中心](https://littleskin.cn/user)

认证服务器地址：

```text
https://littleskin.cn/api/yggdrasil
```

使用方法：

1. 打开 LittleSkin 用户中心并登录。
2. 找到“快速配置启动器”。
3. 将 LittleSkin 配置按钮拖入 HMCL、PCL2 等启动器。
4. 在启动器中选择 LittleSkin 登录。
5. 输入 LittleSkin 账号密码并选择角色。
6. 启动 Minecraft 1.21.1，再使用平时的服务器地址进入。

如果需要手动添加：

| 项目 | 内容 |
| --- | --- |
| 名称 | LittleSkin |
| 地址 | `https://littleskin.cn/api/yggdrasil` |

不要把 MUA Union 地址和 LittleSkin 地址混用。登录哪个渠道，就使用对应渠道的认证地址。

### 第三方账号绑定正版档案

第三方登录默认会作为独立档案进入服务器。

如果希望将 MUA 或 LittleSkin 账号绑定到原本的正版游戏档案，请联系管理员处理。

请提供：

- 第三方登录渠道：MUA Union 或 LittleSkin
- 第三方角色名
- 原正版游戏名
- 需要绑定的服务器账号

管理员确认后会手动处理绑定。请不要在群聊中发送账号密码、Access Token 或其他敏感信息。

## 🖼️ URL 地图画功能移除

由于地图画插件在使用过程中容易造成卡顿，本次更新已移除或禁用 URL 地图画插件。

以下功能暂时不可用：

```mc
/imageframe create
/imageframe list
/imageframe get
/imageframe delete
/imageframe select
```

后续是否重新加入，将根据服务器性能和插件稳定性再决定。

## 🤖 假人及在线人数系统

服务器新增 Fake Player Plugin，用于模拟服务器活跃人数。

当前假人主要显示在：

- TAB 玩家列表
- 服务器列表在线人数
- Velocity 代理在线人数

当前假人不会在世界中生成实体，也不会自动挖矿、放置方块、聊天或加载区块，尽量降低对服务器性能的影响。

### 普通玩家命令

```mc
/fpp help
/fpp spawn
```

`/fpp help` 查看帮助；`/fpp spawn` 创建一个属于自己的假人。普通玩家个人最多拥有 1 个假人。

### 管理员命令

```mc
/fpp spawn <数量>
/fpp spawn <数量> --name <名称>
/fpp list
/fpp stats
/fpp info <假人名称>
/fpp despawn <假人名称>
/fpp despawn all
/fpp rename <旧名称> <新名称>
/fpp save
/fpp reload
```

分别用于批量生成、指定名称生成、查看列表、查看统计、查看假人信息、删除假人、删除全部假人、修改假人名称、保存数据和重载插件配置。
