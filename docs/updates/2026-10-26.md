# 2026.10.26 · SMP 云仓首发与地图画回归

以下内容根据运营者本次确认的更新整理。尚未同步 Discord 频道已确认公告：[服务器更新频道](https://discord.com/channels/1481627208551501999/1504854748170293319)。

## CloudStorage 云仓首次开放

社团自研的 CloudStorage 云仓正式向 SMP 玩家开放。输入 `/cs` 即可打开大箱子界面，集中存取普通可堆叠材料；搜索支持中文、英文和物品 ID。

- 默认使用**全服共享仓**，适合公共材料与工程协作；个人物资请先用 `/cs mode personal` 切换至 UUID 私人仓。
- `/cs deposit all` 批量存入普通材料；`/cs withdraw stone 64` 取出 64 个石头。切换仓库不会搬迁或合并库存。
- 普通玩家可以绑定自有木桶作为世界接口，每人最多 **5 个输入、5 个输出**；仅在所有者在线、区块已加载时工作。
- 搭配指定的云仓适配版投影打印机，可用 `/cs shulker` 获取按需取料的云潜影盒；不用时执行 `/cs shulker off` 释放背包槽位。普通存取无需安装客户端模组。
- 装备、工具、潜影盒及带自定义名称、附魔、容器数据等特殊物品禁止新入库，批量存入时会跳过。

完整操作、界面点击方式与打印机设置见 [SMP 云仓说明](../../servers/smp/#cloudstorage-云仓)。[插件源码](https://github.com/Moeary/Cloud-Storage)和[配套打印机源码与下载](https://github.com/Moeary/litematica-printer-cloud)公开可查。

## ImageFrame 地图画回归

网络图片制作地图画的功能恢复，可以继续用于建筑装饰和作品展示。

```mc
/imageframe create <名称> <图片直链> <宽度> <高度>
/imageframe list
/imageframe get <名称>
```

宽度、高度以地图格数计。图片需使用服务器可访问的直链；创建权限、材料消耗、尺寸及数量限制以当前服内配置为准，不沿用旧公告中的数值。详见 [SMP 地图画说明](../../servers/smp/#imageframe-地图画)。

## 移除 EliteMobs

EliteMobs 使用率较低，且持续产生错误日志，本次将其移除。其精英怪、专属任务与商店等功能不再提供；旧装备或相关数据的处理若有疑问，请联系管理员核对。

## 问题反馈

云仓存取、打印机取料或地图画遇到异常时，请记录发生时间、操作步骤、物品名称与数量，并附截图反馈。云仓显示冻结时请交由管理员审计，不要反复尝试存取。
