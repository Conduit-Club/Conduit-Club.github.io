# 2026.10.02 · 域名、资源与 SMP 更新

根据运营者提供的已确认信息整理。尚未同步 Discord 频道已确认公告：[服务器更新频道](https://discord.com/channels/1481627208551501999/1504854748170293319)。

## 域名迁移

- `shoumc.com` 现在是社团主域名入口，访问时会 301 跳转至 `conduit-club.github.io`，并保留原请求的路径和参数。
- `www.shoumc.com` 保留为 Cloudflare Pages 上的社团官网副本。
- 网页访问和服务器连接使用不同的主机名；连接 Minecraft 服务器时，请使用下面列出的服务器入口。

## Minecraft 服务器入口

后续连接服务器请优先使用以下 `shoumc.com` 子域名：

| 服务器 | 推荐连接地址 | 跨服命令 |
| --- | --- | --- |
| SMP 生存服 | `smp.shoumc.com` | `/server smp` |
| Create 创造建筑服 | `create.shoumc.com` | `/server create` |
| SHOU 建筑展示服 | `shou.shoumc.com` | `/server shou` |

旧 `moear.de` 入口仍见于较早的更新记录和兼容说明，当前连接请优先使用以上新入口。

## SMP 生存服更新

- EliteMobs 加入了汉化。
- 新增支持重复开启不祥宝库的插件，试炼大厅里的同一个不祥宝库现在可以反复开启。

## PCL-CE-SHOU 社团启动器

[PCL-CE-SHOU](https://github.com/Conduit-Club/PCL-CE-SHOU) 是潮涌核心社正在开发的 PCL-CE 社团版启动器，目前主要改进登录方式切换和更有潮涌核心社风格的界面。

Java 登录 API 还需要申请。在申请完成前，仓库 [Releases](https://github.com/Conduit-Club/PCL-CE-SHOU/releases) 中的版本只能使用 MUA Union 或 LittleSkin 登录。详细状态见 [PCL-CE-SHOU 社团启动器](../../community/pcl-ce-shou)。
