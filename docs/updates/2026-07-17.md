# SMP 服务器更新 · 2026-07-17

本轮更新已经上线，新增了一些休闲功能，也调整了模型同步和世界备份策略。

## URL 地图画

现在可以把网络图片制作成游戏内地图画，普通玩家可直接使用。

```mc
/imageframe create <名称> <图片直链> <宽度> <高度>
```

例如，制作一幅 2×3 的地图画：

```mc
/imageframe create example https://i.imgur.com/example.png 2 3
```

其他常用命令：

```mc
/imageframe list                 查看自己创建的图片
/imageframe get <名称>           重新获取已有图片
/imageframe delete <名称>        删除自己的图片
/imageframe select               选择展示框区域
```

- 每位普通玩家最多创建 **64 个图片项目**；一整幅多格画算一个项目。
- 单幅图片最多使用 **100 张地图**，源文件最大 **10 MiB**。
- 生存模式下需要准备与尺寸相同数量的空地图，例如 2×3 需要 6 张。
- 普通玩家暂不开放动态 GIF，避免动画地图造成额外负载。
- 当前支持 Imgur、Discord 图片直链、Minecraft 纹理站和 GitHub Raw 等 HTTPS 图片源。
- Discord 图片链接可能过期，长期展示建议使用稳定的图片直链。

## 椅子与坐下

- 空手右键楼梯、台阶、地毯或雪层即可坐下。
- 按潜行键（默认 `Shift`）起身。
- 也支持玩家之间的坐下互动；不想被互动时可使用 GSit 的切换命令关闭。

## 全员 `/hat`

所有玩家现在都可以使用：

```mc
/hat
```

将手中的物品戴到头上即可；重载权限仍仅限管理员。

## 单人睡眠跳夜

现在只需一名玩家入睡，即可跳过夜晚，不必再等待所有在线玩家上床。

## YSM 模型优化

- 服务器模型库已精简为 **40 个模型**，总计约 **41.8 MiB**。
- 减少进服同步量和模型处理压力，缓解模型过多导致的卡顿。

## 世界备份调整

- 改为每天凌晨 **04:00** 自动备份一次。
- 保留最近 **7 天**的恢复点。
- 备份期间不再关闭世界自动保存，以降低此前“玩家背包正常、方块区块回档”的风险。

## 其他维护

- 已禁用存在问题且暂时不用的 NoteBox 插件。
- 地图画、坐下和帽子插件均已完成加载并投入使用。

如遇到地图画无法读取、图片尺寸异常或其他问题，请带上使用的命令和图片链接反馈。
