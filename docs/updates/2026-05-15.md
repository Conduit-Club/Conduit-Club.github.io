# 2026.05.15 · 服务器现状

因为小团体太多 没人玩Minecraft整合包服务器, 于是关闭整合包服务器. 只留下多个兼容原版的服务器，并通过 Velocity 代理互联,现有服务器如下： 

SMP 生存服：smp.moear.de 
主生存服，有粘液科技 mcmmo相关插件, 支持ysm2.6模组,提供dc-服务器内双向聊天支持. 推荐 Java 1.21.1 进入 

地皮创造建筑服：create.moear.de 
主要用于创造建筑测试使用, 有地皮插件 we插件等. 推荐Java 1.21.11进入

SHOU 学校展示服：shou.moear.de 
主要用于校园建筑展示,纯观察者模式(有bluesky网页预览地图方式 但因为没套域名不方便展示出来 要看的私聊我)。推荐Java 1.21.11进入 

不同服务器之间可以使用/server+服务器名字 命令进行跨服切换 Velocity已装上跨版本插件 无须担心版本不一致导致出问题
