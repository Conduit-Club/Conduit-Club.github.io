# 2026.09.28 · 生存服务器新增插件

本次更新为生存服务器新增 4 个生存与娱乐插件，适用于 Minecraft 1.21.1 兼容构建，玩家无需安装客户端 Mod。

发布日期：2026.09.28

## EliteMobs：野外精英怪

野外会出现更强的精英怪。它们可能拥有更高的生命值、伤害或特殊能力；击杀后有机会获得 EliteMobs 装备、货币等奖励。

常用命令：

```mc
/em
/em help
/em shareitem
```

如果服务器启用了公会功能，还可以使用：

```mc
/ag
```

具体能力、等级和奖励内容以服务器实际启用的插件功能为准。

## AxShulkers 1.24.0：直接打开潜影盒

背包内或手持潜影盒时，可以直接右键打开，无需先将潜影盒放置到地面。

## V-Elevator 1.0.5：便捷上下楼

默认配方为 8 个白色羊毛加 1 个末影珍珠。将电梯放置在相同的 X/Z 坐标后，站上去按跳跃上楼，潜行下楼。

默认搜索楼层最大距离为 50 格，普通玩家默认拥有使用和合成权限。

## PlayerWarps 1.0.5：共享公共传送点

PlayerWarps 用于创建和管理公共传送点，适合聚落、商店、建筑、矿区、景点等地点。

常用命令：

```mc
/pwarp
/pwarp <名称>
/pwarp set <名称>
/pwarp delete <名称>
/pwarp rename <旧名> <新名>
/pwarp seticon <名称>
/pwarp desc <名称> <介绍>
/pwarp manage
```
