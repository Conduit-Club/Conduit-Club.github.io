# Create 创造服

Create 服是用于创造、地皮和建筑制作的 Paper 后端。

进入方式：

```mc
/server create
```

或者直接通过URL进入

```mc
create.moear.de
```

## 常用命令

### 地皮插件

PlotSquared 的命令根为 `/plots`，别名包括 `/p`、`/plot`、`/ps`；具体子命令由当前地皮权限决定：

```mc
/plots help
/plots claim
/plots auto
/plots home
/plots visit <玩家> [编号]
/plots trust <玩家>
/plots add <玩家>
/plots remove <玩家>
/plots delete
```

### 创世神WE插件

WorldEdit 的命令根为 `/we`，别名包括 `/worldedit`、`/wep`、`/wep`；具体子命令请参考 [WorldEdit 官方 Wiki](https://worldedit.enginehub.org/en/latest/commands/)。

```mc
//set <方块> [数据值]
//copy
//paste
//pos1
//pos2
//wand
//undo
//redo
```
