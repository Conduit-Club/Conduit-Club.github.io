# Terraria 社区服

潮涌核心社维护的原版 Terraria（泰拉瑞亚）社区服。这个服独立运行，不经过 Minecraft 的 Velocity 代理，也不能用 `/server` 跨服切换过来。

世界为中型经典难度，默认人数上限 8 人。服务器保留客户端本地角色和背包，未开启服务器端强制角色（SSC），也未安装内容型 Mod；已开启自动保存和定时世界备份。

## 进服方式

1. 打开 Steam 版 Terraria，优先使用 PC 原版 `1.4.5.8`。
2. 在主菜单依次选择「多人游戏 → 通过 IP 加入」，选好角色。
3. 填写公开入口和端口，不用填进服密码（共用进服密码已经取消）：

```text
地址：tr.shoumc.com
端口：7777
```

4. 首次进服后，在游戏聊天栏输入 `/register 你的密码` 创建个人账户，再输入 `/login 你的密码` 登录。以后再进直接登录就行。

:::tip 账户与版本说明

- 账户密码至少 **8 位**，请单独设置，不要复用其他网站密码。未登录前无法正常游玩。
- 服务端装有 `Crossplay 2.5.0`，声明兼容 `1.4.5.0` 至 `1.4.5.8` 客户端，当前关闭旅行模式角色接入，不支持 `1.4.4` 或内容型 Mod。非 `1.4.5.8` 或移动端联机效果以实测为准，优先推荐 PC 原版 `1.4.5.8`。
- 当前未开启白名单；若后续调整，以群内公告为准。

:::

## 账号与基础命令

| 命令 | 说明 |
| --- | --- |
| `/register <密码>` | 首次进服注册个人服务器账户（至少 8 位） |
| `/login <密码>` | 登录服务器账户 |
| `/password <旧密码> <新密码>` | 修改当前账户密码 |
| `/logout` | 退出当前登录的账户 |
| `/help` | 查看当前权限下可用的命令列表 |

## 常用功能与命令

### 传送请求（TeleportRequest）

找队友汇合时，先发传送请求，对方同意后才会传送。当前提示间隔 3 秒，超时重试 3 次。

| 命令 | 中文别名 | 说明 |
| --- | --- | --- |
| `/tpa <玩家名>` | `/传送至玩家 <玩家名>` | 请求传送到对方当前位置 |
| `/tpahere <玩家名>` | `/召唤玩家 <玩家名>` | 请求把对方传送到自己当前位置 |
| `/atp` | `/接受tp` | 同意收到的传送请求 |
| `/dtp` | `/拒绝tp` | 拒绝收到的传送请求 |
| `/autoaccept` | `/自动接受tp` | 自动同意所有人的传送请求 |
| `/autodeny` | `/自动拒绝tp` | 自动拒绝所有人的传送请求 |

### 返回死亡点（Back）

- `/back`：传送回上一次死亡的位置。当前冷却时间为 **20 秒**。

### 房屋圈地保护（HouseRegion）

个人重要建筑和箱子建议用 `HouseRegion` 圈起来保护。当前限制如下：

- 每人最多圈 **2 间**房屋。
- 单间面积上限 **1000 格**，最小宽度 **15 格**，最小高度 **10 格**。
- 房屋内箱子始终受保护；有人强行破坏受保护区域会触发冻结警告。
- 已开启进出房屋提示，也允许直接传送回自己的房屋。

#### 圈地步骤

1. 在聊天栏输入 `/house set 1`，然后敲击目标区域的**左上角**图格。
2. 输入 `/house set 2`，再敲击区域的**右下角**图格。
3. 输入 `/house add <屋名>` 完成创建。

#### 常用圈地命令

| 命令 | 说明 |
| --- | --- |
| `/house help` | 查看圈地操作提示 |
| `/house set 1` | 标记房屋左上角顶点 |
| `/house set 2` | 标记房屋右下角顶点 |
| `/house clear` | 清除临时的顶点标记 |
| `/house add <屋名>` | 按已标记的两点创建房屋 |
| `/house list [页码]` | 查看房屋列表 |
| `/house info <屋名>` | 查看指定房屋的信息和成员 |
| `/house show <屋名>` | 显示指定房屋的边界范围 |
| `/house showall` | 显示所有房屋的边界范围 |
| `/house auto` | 开关进入房屋时自动显示边界 |
| `/house tp <屋名>` | 传送到指定房屋 |
| `/house allow <玩家名> <屋名>` | 添加房屋所有者 |
| `/house disallow <玩家名> <屋名>` | 移除房屋所有者 |
| `/house adduser <玩家名> <屋名>` | 添加房屋使用者（当前限制所有者修改使用者，以服内提示为准） |
| `/house deluser <玩家名> <屋名>` | 移除房屋使用者 |
| `/house lock <屋名>` | 开关房屋锁 |
| `/house redefine <屋名>` | 重新划定已有房屋的范围 |
| `/house delete <屋名>` | 删除指定房屋 |

房屋圈地只保护自己划出的区域，不覆盖整个世界；重要公共建筑可联系管理员额外设置区域保护。

### 留言墙（NoteWall）

全服公共留言板，当前每人最多留 **5 条**，单条不超过 **50 字**。

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `/addnote <内容>` | — | 发布一条留言 |
| `/notewall [页码\|help]` | — | 分页浏览留言墙或查看帮助 |
| `/vinote <序号\|玩家名>` | `/viewnote` | 查看指定序号或玩家的留言 |
| `/mynote` | — | 查看自己留过的历史留言 |
| `/rdnote` | `/randomnote` | 随机看一条留言 |
| `/upnote <序号> <新内容>` | `/updatenote` | 修改自己的留言 |

删除留言（`/delnote`）归管理员权限；发现不当内容可联系管理员处理。

### Boss 伤害统计与自动播报

- **Boss 伤害统计（DamageStatistic）**：每次击败 Boss 后，聊天栏会自动显示每位玩家造成的伤害，不用手动输入命令。
- **定时提示（AutoBroadcast）**：聊天栏每隔 **15 分钟**播报一次常用指令提醒。

## 已安装插件清单

以下按当前部署核对，分为玩家日常会用到的插件和服内基础维护插件。具体权限、配额和版本若后续调整，以服内实际配置为准。

| 插件 | 版本 | 作用 | 使用对象 |
| --- | --- | --- | --- |
| `TShock`（`TShockAPI`） | `6.2.1` | 服务端核心，负责账户认证、权限组、自动保存与定时世界备份 | 全服 / 玩家用基础命令 |
| `Crossplay` | `2.5.0` | `1.4.5.0`–`1.4.5.8` 跨版本协议兼容（关闭旅行模式角色） | 自动生效 |
| `TeleportRequest` | `1.0.4.1` | 玩家互传请求（`/tpa`、`/tpahere`、`/atp`、`/dtp` 等） | 普通玩家 |
| `Back` | `1.0.0.11` | 返回上次死亡地点（`/back`，冷却 20 秒） | 普通玩家 |
| `HouseRegion` | `1.0.5.1` | 房屋圈地与箱子保护（`/house`） | 普通玩家 |
| `NoteWall` | `1.0.3.1` | 全服公共留言墙（`/addnote`、`/notewall` 等） | 普通玩家 |
| `DamageStatistic` | `1.1.0.1` | 击杀 Boss 后自动统计玩家伤害 | 自动生效 |
| `AutoBroadcast` | `1.1.4.1` | 聊天栏定时播报常用命令提示 | 自动生效 |
| `History` | `1.0.9.1` | 记录图格修改历史，供建筑遭破坏或误操作时查询回滚 | 管理员维护 |
| `BetterWhitelist` | `2.6.5.1` | 按角色名控制白名单（当前未开启） | 管理员维护 |
| `PersonalPermission` | `1.1.0.7` | 为单个玩家单独分配权限 | 管理员维护 |
| `AutoPluginManager` | `2.1.0.4` | 插件管理工具（当前关闭自动更新和热重载） | 管理员维护 |

核心与插件公开来源：[Pryaxis/TShock v6.2.1](https://github.com/Pryaxis/TShock/releases/tag/v6.2.1)、[nayetdet/TerrariaCrossplay v2.5.0](https://github.com/nayetdet/TerrariaCrossplay/releases/tag/v2.5.0)、[UnrealMultiple/TShockPlugin](https://github.com/UnrealMultiple/TShockPlugin)。

## 游玩规范与反馈

- 尊重其他玩家的建筑和箱子，动别人东西前先问一声；重要建筑记得及时用 `/house` 圈地。
- 进服连不上、遇到建筑破坏或插件异常时，在群里发一下客户端版本、报错截图或大致时间地点，方便一起排查，必要时由管理员通过 `History` 核查回滚。
