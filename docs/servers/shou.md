# 建筑展示服

建筑展示服用于参观已完成的作品。

进入方式：

```mc
/server shou
```

或者直接通过URL进入

```mc
shou.moear.de
```

## 参观提示

- 该服默认为旁观模式，适合浏览作品和地图，不是主要建造服。
- 建造与大范围编辑请前往 [Create 机械服](/create/)。
