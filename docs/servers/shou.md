# SHOU 建筑展示服

SHOU 建筑展示服用于参观已完成的作品。

进入方式：

```mc
/server shou
```

也可以在 Minecraft 多人游戏中直接填写：

```mc
shou.shoumc.com
```

原入口 `shou.moear.de` 继续可用，无需填写端口。

## 参观提示

- 该服默认为旁观模式，适合浏览作品和地图，不是主要建造服。
- 建造与大范围编辑请前往 [Create 创造建筑服](/servers/create/)。
